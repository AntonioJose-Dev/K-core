## 3. G.ET — creación (contenido del procedimiento)

### 3.1 Autoridad

La autoridad para proponer, revisar, firmar, activar, poner en sombra y revertir versiones del contrato EfectoTipado y tablas operativas asociadas es el **órgano de firmantes registrados G.ET**, actuando bajo el rol G.ET (objeto firmado: `efecto-tipado@vN` u homólogo, **no** un paquete normativo G.5).

### 3.2 Registro de firmantes

Debe existir un registro de firmantes G.ET con, como mínimo:

- un firmante con **competencia jurídica** registrada;  
- un firmante con **competencia técnica** registrada;  
- **identidades distintas**.

Hasta que ese registro esté poblado y esta enmienda vigente, **no hay G.ET operativo**.

### 3.3 Umbral

Umbral ordinario G.ET: **≥ 2 de N**, con al menos un jurídico y un técnico distintos (espíritu G.5.4; sin cobertura G.5 alegada).

### 3.4 Etapas (gobierno posterior a la vigencia de esta enmienda)

| Etapa | Contenido |
|---|---|
| ET.1 Propuesta | Esquema / versión + vectores de conformidad |
| ET.2 Revisión | Jurídica + técnica |
| ET.3 Conformidad | Harness + diff de tipificaciones reconocido y firmado |
| ET.4 Doble firma | Umbral §3.3 |
| ET.5 Sombra | Periodo de sombra sin aplicar a ALLOW reales (p. ej. 7 días, fijable en el primer ciclo) |
| ET.6 Activación | Límite de época; versión anterior conservada |
| ET.7 Reversión | Mismo umbral; no borrar historia |

Nueva clase o redefinición de clase de efecto: decisión firmada de reapertura de §C **más** actualización de esquema por G.ET (solo tras vigencia de esta enmienda).
