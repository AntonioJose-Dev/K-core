## 3. G.ET — creación (contenido del procedimiento)

### 3.1 Autoridad

La autoridad para proponer, revisar, firmar, activar, poner en sombra y revertir versiones del contrato EfectoTipado y tablas operativas asociadas es el **órgano de firmantes registrados G.ET**, actuando bajo el rol G.ET (objeto firmado: `efecto-tipado@vN` u homólogo, **no** un paquete normativo G.5).

G.ET **no** puede alterar la Matriz fuera de una enmienda fundacional humana (§0.4).

### 3.2 Registro de firmantes

Debe existir un registro de firmantes G.ET con, como mínimo:

- un firmante con **competencia jurídica** registrada;  
- un firmante con **competencia técnica** registrada;  
- **identidades distintas**.

Hasta que ese registro esté poblado y esta enmienda vigente, **no hay G.ET operativo**.

### 3.3 Umbral
